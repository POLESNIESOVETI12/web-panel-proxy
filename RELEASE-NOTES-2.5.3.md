# WEB PANEL PROXY 2.5.3

## Меньше фоновой нагрузки

- Сбор счётчиков подключений выполняется раз в 30 секунд вместо 10.
- Системные метрики собираются раз в минуту вместо 10 секунд.
- Дашборд обновляет данные раз в 15 секунд вместо 5.
- Состояние всех пользовательских служб теперь читается одним вызовом `systemctl`, а не отдельным процессом для каждого подключения.
- Xray Stats API не запускается, если нет активных VLESS/Hysteria2-профилей.
- Суточная история метрик хранит минутные точки и занимает заметно меньше места.

Учёт общего трафика, лимиты, графики и состояние служб сохранены. На очень слабых VPS
эффект можно проверить по `systemd-cgtop`, `top` и числу запусков служб-сборщиков.

## Резервная копия на компьютере

Во вкладке **Настройки** появились две операции:

- скачать переносимый ZIP с клиентами, подписками, ключами, подключениями, нодами,
  настройками OpenFlux и опубликованным сайтом;
- выбрать этот ZIP и восстановить настройки после переустановки панели.

Архив проверяется по строгому списку путей, размерам и SHA-256 перед применением.
Он содержит секретные данные и должен храниться в безопасном месте.

## Без накопления копий на VPS

Обновление создаёт снимок только во временном каталоге `/tmp`, использует его для
автоматического отката и удаляет после завершения. Старые каталоги автоматических
снимков версий до 2.5.3 удаляются после первого успешного обновления.
