# WEB PANEL PROXY 2.5.1

Стабильный выпуск новой модели управления WPP: серверные подключения теперь создаются отдельно, а клиенты получают выбранные отдельные ключи или подписки.

## Главное

- VLESS XHTTP напрямую или через Yandex Cloud, VK Cloud, Beget, Selectel и собственный CDN.
- Редактирование CDN-подключения без замены UUID и клиентских ключей.
- CDN Doctor с диагностикой всей цепочки и безопасным восстановлением локальных маршрутов WPP.
- Hysteria2, MTProto, Web Proxy и OpenFlux в общем интерфейсе.
- Ограничения трафика и устройств, подписки и объединение нескольких VPS через ноды.
- Увеличенные QR-коды и адаптивные окна для компьютера и телефона.
- Правдоподобные XHTTP-пути к статическим файлам вместо технического префикса `vless`; старые ссылки сохраняют совместимость.
- Ручные и добровольные автоматические обновления с резервной копией и откатом.

## Совместимость

- Ubuntu 22.04 и 24.04, Debian 12.
- Архитектура x86_64.
- Обновление сохраняет пользователей, ключи, настройки, адрес панели и публичный сайт.

## Установка

```bash
sudo -i bash -c 'curl -4fsSL "https://raw.githubusercontent.com/POLESNIESOVETI12/web-panel-proxy/v2.5.1/install.sh" -o /tmp/wpp-install.sh && bash /tmp/wpp-install.sh; code=$?; rm -f /tmp/wpp-install.sh; exit $code'
```

Команда заработает после загрузки исходников релиза и создания тега `v2.5.1` в GitHub.
