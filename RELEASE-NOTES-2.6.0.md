# WEB PANEL PROXY 2.6.0

Версия 2.6.0 — крупное обновление панели после 2.5.4. Основное внимание уделено управлению подключениями, Xray-маршрутизации, обновлению компонентов, скорости интерфейса и снижению фоновой нагрузки.

## Что изменилось с версии 2.5.4

### Подключения

- Серверные подключения вынесены в отдельный раздел и управляются независимо от клиентов и подписок.
- Добавлено создание отдельных подключений VLESS XHTTP, Hysteria2, MTProto, WEB Proxy и AmneziaWG 2.0/3.1.
- VLESS XHTTP поддерживает прямое подключение и CDN-маршруты с настройкой домена, SNI, Host, fingerprint, режима XHTTP и метода uplink.
- В настройках существующего подключения отображается фактический inbound из активной конфигурации Xray.
- Добавлена экспертная настройка серверной и клиентской частей Xray без пересоздания пользовательских ключей.
- При выборе подключений подписки показываются только созданные серверные подключения, без повторов от самих подписок.
- OpenFlux перенесён в общий список клиентов: профиль можно создать, включить, остановить, скопировать или удалить из одного интерфейса.
- Для OpenFlux сохранены отдельные режимы Яндекс, Mail.ru и MAX, а также совместимость с iOS и Android.

### Xray-маршрутизация

- Добавлен отдельный раздел «Маршрутизация» с привязкой правил к конкретному VLESS или Hysteria2-подключению.
- Маршрутизация теперь формируется внутри полноценной Xray-конфигурации, а не добавляется в Happ отдельной служебной ссылкой.
- Поддерживаются прямой доступ к российским и локальным ресурсам, отдельные proxy-исключения, раздельный DNS и блокировка BitTorrent.
- Смешанные подписки сохраняют VLESS, Hysteria2 и совместимые подключения удалённых нод в одном профиле.
- Для каждого подключения хранится собственное состояние маршрутизации.
- Маршрутизацию можно полностью убрать с выбранного подключения, не удаляя само подключение, клиентов, ключи или правила других подключений.
- Новые подключения не получают маршрутизацию автоматически — она включается только после явного сохранения администратором.
- Настройки маршрутизации включены в резервное копирование и восстановление панели.

### Интерфейс

- Убраны повторяющиеся заголовки страниц, лишние пояснения и пустое пространство над рабочими разделами.
- Основные кнопки встроены непосредственно в карточки и списки, поэтому полезное содержимое начинается выше.
- Переработаны страницы дашборда, подключений, клиентов, маршрутизации, CDN Doctor, нод и обновлений.
- Список подключений в настройках клиента стал компактнее и удобнее для большого количества серверов.
- Переключение между разделами выполняется плавно, без визуального сжатия, двойных кадров и полной перезагрузки оболочки панели.
- Активный пункт меню меняется сразу после нажатия; поддерживаются кнопки браузера «Назад» и «Вперёд».
- Для системного режима уменьшения движения анимации автоматически отключаются.
- Обновлены управляющие иконки, кнопки закрытия и состояния загрузки форм.
- Экран входа стал компактнее и не содержит лишнего приветственного текста.

### Обновления Xray и OpenFlux

- Добавлен единый менеджер версий панели, Xray и OpenFlux.
- Установка компонентов показывает прогресс от 0 до 100%: загрузка, проверка, резервная копия, замена и контроль запуска.
- Ошибки разделены по причинам и сопровождаются понятной подсказкой; технические подробности можно раскрыть отдельно.
- Если новая версия не запускается, автоматически восстанавливается предыдущий рабочий бинарник.
- После чистой установки или обновления панели сразу выполняется проверка актуальных стабильных Xray и OpenFlux.
- Фоновый таймер проверяет новые стабильные версии каждые шесть часов.
- Каталог Xray загружается из официальных Releases проекта XTLS.
- Каталог OpenFlux загружается только из официальных Releases `p1neappleXpress/OpenFlux`; обычные Git-теги без опубликованного релиза не отображаются.
- OpenFlux `v0.13.0` показывается в панели понятным номером ядра `1.6.0`.
- Тестовые OpenFlux-сборки имеют понятную дату и доступны только для ручного выбора; автоматическое обновление предпочитает номерные релизы.

### Производительность и диагностика

- Состояние системных служб читается одним запросом и повторно используется из короткого кэша.
- Интервал тяжёлого сбора трафика и фонового обновления дашборда увеличен до 60 секунд; ручное обновление остаётся мгновенным.
- Убраны неиспользуемые общие Xray-счётчики, при этом пользовательская статистика upload/download сохранена.
- Индикатор процессора теперь показывает нагрузку самой VPS, а ожидание физического процессора гипервизора (`steal`) выводится отдельно.
- Добавлен режим экономии CPU для MTProxy: неиспользуемые WEB Proxy и MTProto-службы можно остановить, не затрагивая Xray, Hysteria2, AmneziaWG, OpenFlux, Caddy и панель.
- При создании активного WEB Proxy или MTProto-клиента нужные службы запускаются автоматически.
- CDN Doctor очищен от навязчивых рекомендаций и оставляет только фактическую диагностику текущего подключения.

### Установка и обновление панели

- Новая установка и обновление используют одну безопасную схему с проверкой состава пакета и состояния служб.
- Обновление сохраняет пользователей, подписки, ключи, подключения, настройки, адрес панели и пользовательские HTML-страницы.
- Перед заменой файлов создаётся временный снимок для автоматического отката при ошибке.
- Порт `80/tcp` не занимается: HTTPS-сертификат выпускается и продлевается через TLS-ALPN на `443/tcp`.
- Поддерживаются Ubuntu 22.04+ и Debian 12+ на архитектуре `x86_64`.

## Обновление с 2.5.4

Обновление выполняется поверх существующей установки. Пользователи, ключи, подписки и настройки сохраняются.

```bash
/usr/local/sbin/web-panel-proxy-update
```

Перед обновлением рекомендуется скачать резервную копию из панели. После завершения проверьте разделы «Подключения», «Маршрутизация» и «Обновления».
