<h1 align="center">WEB PANEL PROXY 2.8.1</h1>

<p align="center">WEB Proxy, MTProto, VLESS XHTTP, Hysteria2, NaiveProxy, Mieru, OpenFlux и аккуратная панель управления для собственного VPS</p>

## Возможности

- Подписки и отдельные подключения с QR-кодами и готовыми конфигурациями.
- VLESS XHTTP и Hysteria2, включая прямые и CDN-подключения VLESS.
- Отдельные профили AmneziaWG 2.0 и 3.1 с QR-кодом и файлом `.conf`.
- NaiveProxy и Mieru с отдельным портом для каждого серверного подключения, ссылкой и QR-кодом.
- Отдельные профили MTProto и Telegram Web Proxy; экспериментальная интеграция OpenFlux через Яндекс Документы, Телемост, Mail.ru и MAX.
- Управление пользователями, ограничениями устройств, трафиком и состоянием служб.
- Переключение доступа без перезагрузки страницы: зелёное уведомление при включении, красное при выключении.
- Объединение нескольких VPS в одну подписку через Node API token.
- Автоматическое определение страны ноды с отображением флага.
- Готовые HTML-заглушки и собственные страницы с HTML, CSS, JavaScript, SEO и аналитикой.
- Проверка обновлений и безопасное обновление с временным автоматическим откатом.
- Ручной экспорт и импорт полной резервной копии настроек через браузер без накопления архивов на VPS.


## Требования

- Чистый VPS с Ubuntu 22.04+, Ubuntu 24.04+ или Debian 12+.
- [Аренда VPS](https://play2go.cloud/?ref_id=m1o4quWG0sE)
- Архитектура `x86_64` и доступ пользователя `root`.
- Домен или поддомен с A-записью на публичный IPv4 сервера.
- Свободный и открытый `443/tcp`. Порт `80/tcp` панель не занимает.

Перед установкой убедитесь, что домен уже указывает на сервер. Дополнительные порты выбранных подключений панель покажет автоматически; их также нужно открыть во внешнем firewall личного кабинета VPS-провайдера.

Установщик MTProxy сначала получает актуальные служебные файлы с `core.telegram.org` по HTTPS через IPv4. Для каждой из двух загрузок установлены тайм-аут соединения 10 секунд, ограничение одной попытки 30 секунд и одна повторная попытка. При недоступности адреса или некорректном ответе используются проверенные общедоступные файлы Telegram из пакета (снимок от 2026-10-31). Резервные копии проверяются по формату и SHA-256; повреждённые данные отклоняются. Снимок не блокируется по календарной дате; актуальные сетевые данные всегда имеют приоритет. Другие загрузки установщика выполняются как прежде. Успешное получение служебных файлов само по себе не подтверждает связь MTProxy с серверами Telegram.

## Быстрый старт

Подключитесь к серверу по SSH и перейдите в режим `root`:

```bash
sudo -i
```

### Установка

```bash
sudo -i bash -c 'curl -4fsSL "https://raw.githubusercontent.com/POLESNIESOVETI12/web-panel-proxy/v2.8.1/install.sh" -o /tmp/wpp-install.sh && bash /tmp/wpp-install.sh; code=$?; rm -f /tmp/wpp-install.sh; exit $code'
```

Команда доступна после публикации тега `v2.8.1` в GitHub. Установщик запросит домен, email для HTTPS-сертификата, логин и пароль панели. После установки он покажет адрес панели и данные для входа.

Локальная установка из ZIP:

```bash
apt-get -o DPkg::Lock::Timeout=600 install -y unzip && d=$(mktemp -d /root/wpp-install.XXXXXX) && unzip -q /root/WEB-PANEL-PROXY-V-2.8.1-GITLAB.zip -d "$d" && cd "$d" && chmod +x ./*.sh && bash ./install-final.sh
```

### После установки

1. Сохраните адрес панели, логин, пароль и Node API token в безопасном месте.
2. Откройте показанный HTTPS-адрес панели и создайте пользователя или отдельное подключение.
3. Скачайте конфигурацию, скопируйте ссылку либо отсканируйте QR-код подходящим клиентом.
4. Для удалённой ноды установите эту же версию WPP на втором VPS и добавьте её Node API token во вкладке **Ноды**.

### Обновление

```bash
/usr/local/sbin/web-panel-proxy-update
```

Обновление устанавливает последний стабильный релиз и сохраняет пользователей, ключи, настройки, адрес панели и HTML-заглушки.

Локальное обновление из ZIP (сначала загрузите архив в `/root`):

```bash
d=$(mktemp -d /root/wpp-update.XXXXXX) && unzip -q /root/WEB-PANEL-PROXY-V-2.8.1-GITLAB.zip -d "$d" && cd "$d" && chmod +x ./*.sh && ./update.sh --local
```

### Удаление

```bash
/usr/local/sbin/web-panel-proxy-uninstall
```

> **Внимание:** удаление выполняется без дополнительного подтверждения и стирает пользователей, ключи, конфигурации, службы и сайт WEB PANEL PROXY.

## Сеть и порты

| Назначение | Порт |
|---|---:|
| HTTPS, панель, защищённые подключения и продление сертификата | `443/tcp` |
| Hysteria2 по умолчанию | `8443/udp` |
| MTProto | выбранный порт, обычно `2399–2430/tcp` |
| NaiveProxy | отдельный порт подключения, по умолчанию от `53000/tcp` |
| Mieru | отдельный порт подключения, по умолчанию от `54000/tcp` или UDP |

Для Shadowrocket используйте ссылку Mieru `mierus://` или её QR-код. В настройках клиента также доступен полный профиль `mieru://` для официального приложения mieru CLI. Это два варианта экспорта одного ключа; создавать нового пользователя не нужно.

Если для отдельного VLESS/Hysteria2 включена маршрутизация, основная кнопка копирования и QR передают в Happ ссылку на полный JSON одного сервера. В настройках пользователя доступны «Добавить в Happ», просмотр, копирование и скачивание JSON. Обычная `vless://`-ссылка сохранена отдельно и не содержит DNS и правил маршрутизации. После изменения правил обновите JSON-профиль в Happ.

Для NaiveProxy и Mieru пока доступны отдельные ключи без подписки, учёта трафика и ограничений по трафику или числу устройств. После изменения настроек ключа обновите его в приложении.

Клиентские ссылки Timeweb XHTTP используют путь с окончанием `/stream/index.json`. Серверный путь в редакторе Xray остаётся `/stream`: Caddy передаёт и вложенные пути, поэтому менять серверный JSON вручную не нужно. После обновления панели обновите подписку в Happ либо заново скопируйте и добавьте отдельное подключение. Ключи и UUID сохраняются.

Caddy использует `443/tcp`; сертификат выпускается и продлевается через TLS-ALPN без постоянного HTTP-слушателя. Порт `80/tcp` остаётся свободным. Если используется UFW, панель добавит свои правила, но firewall у VPS-провайдера необходимо настроить отдельно.

## Проверка состояния

JSON существующего VLESS/Hysteria2 открывается карандашом в строке подключения → «Конфигурация Xray». Это серверный inbound выбранного подключения, а не общий конфиг службы. Сохраняются локальный порт, путь XHTTP, tag и остальные параметры inbound. При сохранении согласовываются маршруты Caddy, клиентские ссылки и UDP-порт Hysteria2; неверная конфигурация откатывается. UUID/пароли остаются в разделе «Пользователи», DNS/routing — в разделе «Маршрутизация»; попытка изменить управляемые поля вызывает ошибку, а не молча теряет правку. Для VLESS сохраняется существующая схема XHTTP за Caddy (локальный inbound без TLS). Если несколько строк используют один физический inbound, редактор показывает предупреждение с их названиями.

Открыть консольное меню:

```bash
WPP
```

Проверить службы и последние сообщения панели:

```bash
systemctl --failed --no-pager
journalctl -u tproxy-panel.service -n 100 --no-pager
```

Проверить занятые порты:

```bash
ss -lntup
```

## Полезно знать

- Адрес панели, Node API token и ссылки подключений являются секретными — не публикуйте их.
- Для отката обновления создаётся временный снимок, который автоматически удаляется после проверки.
- Для OpenFlux через документы требуется отдельная подходящая публичная ссылка для каждого профиля; для Телемоста — отдельная конференция для пары «клиент — сервер».
- QR-код OpenFlux содержит данные доступа. Не публикуйте его и удаляйте профиль при потере устройства.
- Статус «Работает» у профиля OpenFlux означает, что его служба запущена; наличие интернет-трафика проверяется отдельно.
- OpenFlux — экспериментальная IPv4-интеграция. Совместимость UDP зависит от клиента и режима и не проверена этой сборкой; IPv6-туннель не предоставляется.
- Скачиваемые резервные копии содержат пароли и ключи — храните их безопасно и не загружайте в публичный репозиторий.
