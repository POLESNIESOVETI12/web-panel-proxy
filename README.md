WEB PANEL PROXY V 2.0 — установщик Telegram WEB Proxy и веб-панели управления для VPS.

[АРЕНДОВАТЬ VPS И ДОМЕН]((https://play2go.cloud/?ref_id=m1o4quWG0sE)

Панель создаёт отдельные подключения для пользователей, показывает QR-код и ссылку для Telegram, а также позволяет менять HTML главной страницы сайта.

## Возможности

- Установка одной командой на Ubuntu 22.04+ или Debian 12+ с безопасным продолжением после прерванной установки.
- Telegram WEB Proxy через HTTPS/443.
- Веб-панель по защищённому случайному адресу.
- Создание и удаление пользовательских подключений.
- Уникальный Secret и QR-код для каждого пользователя.
- Копирование готовой ссылки подключения для Telegram.
- Редактор HTML главной страницы и четыре встроенных пресета заглушек, включая «КОТИКИ ЧИНЯТ САЙТ».
- Смена пароля администратора в панели.
- Закреплённая навигация и отдельная кнопка выхода.
- Обновление самой первой версии без панели с созданием учётной записи администратора.
- Полное удаление компонентов проекта отдельным скриптом.

## Требования

- VPS с Ubuntu 22.04+ или Debian 12+.
-[АРЕНДОВАТЬ VPS И ДОМЕН]((https://play2go.cloud/?ref_id=m1o4quWG0sE)
- Домен или поддомен с A-записью, направленной на IPv4 вашего VPS.
- Открытые порты `80` и `443`.
- Доступ к серверу от пользователя `root`.
- Если Caddy уже установлен, его бинарник, служба и посторонние сайты сохраняются; установщик добавляет или обновляет только блок выбранного домена WEB Proxy.
- Порты `80/443` могут быть заняты Caddy. Другой веб-сервер на этих портах необходимо настроить отдельно или остановить, поскольку два процесса не могут слушать один порт одновременно.

## Установка одной командой

Подключитесь к VPS и выполните:

[АРЕНДОВАТЬ VPS И ДОМЕН]((https://play2go.cloud/?ref_id=m1o4quWG0sE)

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/POLESNIESOVETI12/web-panel-proxy/v2.0.2/install.sh)"
```

Во время установки укажите:

1. Домен, например `proxy.example.com`.
2. Email для выпуска HTTPS-сертификата.
3. Логин и пароль администратора панели длиной не менее 3 символов.

В конце установки будут выведены адрес панели, логин и пароль. Сохраните эти данные в безопасном месте.

Повторный запуск установщика не требует предварительно удалять Caddy, MTProxy или relay: совместимые работающие компоненты переиспользуются, недостающие устанавливаются. Для уже настроенной панели сохраняются пользователи, пароль, приватный адрес и HTML-заглушка.

## Работа с панелью

Откройте URL панели, который показал установщик, и войдите с указанными данными.

### Пользователи

Во вкладке **Пользователи**:

1. Введите имя.
2. Нажмите **Создать WEB Proxy**.
3. Нажмите **QR-код** и отсканируйте его в Telegram либо нажмите **Скопировать ссылку**.
4. Для удаления подключения нажмите **Удалить** напротив пользователя.

Основной Secret установки удалить нельзя.

### Настройки

Во вкладке **Настройки** можно:

- применить один из HTML-пресетов для главной страницы;
- вставить свой HTML-код главной страницы;
- сменить пароль администратора.

Боковая навигация на компьютере остаётся на месте при прокрутке содержимого. Кнопка **Выйти** завершает текущую сессию панели.

Перед заменой HTML сохраняется резервная копия. Панель выносит встроенные CSS, JavaScript и атрибуты `style` в локальные файлы с уникальными именами, поэтому браузер не смешивает кэш разных пресетов. Доступность файлов проверяется через relay после перезапуска.

### Своя HTML-заглушка

Вставляйте полный HTML одним файлом: стили внутри `<style>`, атрибуты `style="..."` и скрипты внутри `<script>` панель автоматически подготовит для WEB Proxy. Не используйте CDN, внешние шрифты/библиотеки, внешние изображения и inline-обработчики вроде `onclick="..."`: relay намеренно блокирует сторонние ресурсы и небезопасные обработчики. Все нужные стили и скрипты должны быть внутри вставленного HTML, а события подключены через `addEventListener`.

## Обновление одной командой

Для уже установленного WEB PANEL PROXY используйте отдельную безопасную команду:

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/POLESNIESOVETI12/web-panel-proxy/v2.0.2/update.sh)"
```

Обновление меняет файлы панели, но сохраняет пользователей, секреты, пароль администратора, приватный адрес панели и HTML-заглушку сайта. Перед началом автоматически создаётся резервная копия в `/root/web-panel-proxy-update-backup-ДАТА-ВРЕМЯ`. Relay сначала проходит тесты и проверку конфигурации; при ошибке предыдущий бинарник и состояние панели восстанавливаются автоматически.

Если обнаружена самая первая версия WEB Proxy без панели, обновление извлекает существующие домен и основной Secret, затем предлагает создать логин и пароль администратора. Пароль вводится один раз и должен содержать минимум 3 символа; после этого создаются панель и её приватный адрес.

## Удаление одной командой

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/POLESNIESOVETI12/web-panel-proxy/v2.0.2/uninstall-web-proxy.sh)"
```

Также после обычной установки доступна локальная команда:

```bash
sudo /usr/local/sbin/web-panel-proxy-uninstall
```

Скрипт не просит вводить подтверждение. Он останавливает и удаляет службы, правила firewall, конфигурации, Secrets, панель, сайт и компоненты WEB PANEL PROXY V 2.0. Если после установки в Caddy были добавлены другие сайты, удаляется только блок домена WEB PANEL PROXY, а остальные сайты и Caddy сохраняются.

## Безопасность

- Backend- и статистические порты закрываются постоянной службой `web-proxy-panel-firewall.service`.
- Служба firewall повторно применяет правила после запуска или перезапуска `nftables` и стартует раньше пользовательских proxy-служб.
- После 8 неудачных попыток входа с одного адреса авторизация временно блокируется.
- Сессии подписываются HMAC-SHA256; смена пароля завершает все ранее выданные сессии.
- Установщик и обновление используют тег `v2.0.2`, а исходники relay зафиксированы на проверенном commit.
- Дополнительно рекомендуется разрешить во внешнем firewall провайдера только `22`, `80` и `443`.
